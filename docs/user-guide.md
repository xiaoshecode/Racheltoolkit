# 吉老师个人教学空间使用指南

本指南面向任课教师和学生。简版步骤也可随时在[站内使用指南](https://rachelteacher.online/help/)查看。操作名称按当前网站页面编写；示例姓名、学号和分数均为虚构数据。

## 先确认打开的是教学站

[GitHub Pages 公开入口](https://xiaoshecode.github.io/Racheltoolkit/)已接通[教学站](https://rachelteacher.online/)。查看课程可从这两个入口进入；登录、编辑、上传和学生注册均在 `rachelteacher.online` 完成。公开代码仓库不是登录入口。

完整教学站的课程目录位于 `/`，登录页位于 `/login/`，学生注册页位于 `/register/`。学生使用本人完整学号与网站密码，无需 GitHub 或云盘账号。本文提到的路径均相对于教学站域名。

本机验收使用独立虚构数据，启动方法和体验账号位置见[仓库说明](../README.md#本机验收)。正式账号、班级、任教权限、私有资料库及服务器初始化由管理员按[部署手册](../deploy/README.md)配置；体验账号不能代替正式账号。

## 管理员：首次建立课程与教师权限

空站需要先创建课程、教学班和授权关系，教师工作台才会出现相应入口。打开[管理后台](https://rachelteacher.online/admin/)，使用管理员账号登录，依次完成以下操作。后台部分模型名称为英文，可按表中链接直接打开新增页。

| 顺序 | 后台项目 | 填写方法 |
| --- | --- | --- |
| 1 | [Term：学期](https://rachelteacher.online/admin/school/term/add/) | `Code` 填学期名称，例如 `2026-2027 第一学期`。 |
| 2 | [Course：课程](https://rachelteacher.online/admin/school/course/add/) | `Code` 填唯一课程编号，例如 `MATH-01`；`Title` 填课程名称。 |
| 3 | [Teaching class：教学班](https://rachelteacher.online/admin/school/teachingclass/add/) | `Term` 选择学期，`Course` 选择课程，`Code` 填班名，例如 `高一 1 班`。同一门课程可有多个教学班。 |
| 4 | [Course editor：课程编辑授权](https://rachelteacher.online/admin/school/courseeditor/add/) | `Course` 选择课程，`Teacher` 选择负责编辑的教师账号。 |
| 5 | [Teaching assignment：任教关系](https://rachelteacher.online/admin/school/teachingassignment/add/) | `Teaching class` 选择教学班，`Teacher` 选择任课教师，保留 `Active` 勾选。 |

首次可以在第 4、5 步选择自己的管理员账号。若另有老师，先在后台的[用户](https://rachelteacher.online/admin/auth/user/)中新增账号和初始密码，保存后补充姓名，再为该账号配置上述两种授权。普通教师仅使用教师工作台时，无需勾选职员或超级用户权限；不要使用学生自助注册来创建教师。

**管理员身份、课程编辑权和任教关系彼此独立。** 管理员要在教师工作台编辑课程，也需要 `Course editor`；要发放班级邀请码、布置作业和查看班级成绩，还需要有效的 `Teaching assignment`。完成后打开[工作台](https://rachelteacher.online/me/)，应能看到“准备课程资料”和“我的教学班级”。

后续的章节正文和资料上传都在“课程编辑”中进行，无需在后台逐条编辑课程版本或文件记录。还没有发布任何课程时，公开目录为空属于正常情况。

## 学生：使用班级邀请码注册

适用于老师没有预先导入账号的新学生：

1. 从任课老师处领取班级邀请码，打开[学生注册](https://rachelteacher.online/register/)，也可从登录页进入注册。
2. 填写完整学号、姓名、邀请码和自己的密码，再次输入密码确认。学号开头的零必须保留；使用学校统一分配的学号，避免不同学生填入同一个账号。
3. 提交成功后，账号自动获得该班的有效选课关系。按页面提示登录，进入“学习概览”查看本班作业。
4. 已有本站账号时，先[登录](https://rachelteacher.online/login/)，再打开[加入班级](https://rachelteacher.online/join/)，用另一班的邀请码加入，无需重复注册账号。

邀请码只用于加入老师指定的班级，不会赋予教师或管理员权限。邀请码不是实名核验：老师应只向本班学生发放，并核对入班名单。自己的密码不要交给老师或其他同学。

如果学号已存在，不能用班级邀请码覆盖原账号或设置它的密码。已导入但尚未激活的学生，应领取与本人账号绑定的一次性激活凭证，按下一节操作；已有密码则直接登录。被停用的选课关系也不能通过邀请码自行恢复，请联系老师处理。

## 已导入账号：激活、登录与重设密码

1. 向学校管理员领取与本人账号对应的一次性凭证，凭证一小时内有效。
2. 在登录页点击“首次激活”，填写完整学号或教师账号、一次性凭证、新密码及确认密码，点击“设置密码”。
3. 回到登录页输入账号与密码。学号开头的零必须保留。
4. 忘记密码时先领取新的重设凭证，再从登录页进入“重设密码”。旧密码与旧登录会话在重设后失效。
5. 共用设备使用完毕后点击右上角“退出”。

个人主页为 `/me/`。学生可从“我的作业”“我的成绩”“我的错题”进入相应页面；教师可见获授权的教师工作台。没有班级、课程编辑入口或成绩册时，请由管理员核对选课、任教和课程编辑权限。

## 教师：准备名册与课程

### 发放班级邀请码

在工作台打开[班级邀请码](https://rachelteacher.online/teacher/invitations/)，仅能管理自己有效任教的班级。

1. 选择教学班，设置有效天数和可加入人数。默认 **7 天、30 人**；有效期可设为 1–30 天，名额可设为 1–500 人。
2. 生成后立即复制并妥善保存邀请码，再把邀请码和[学生注册页](https://rachelteacher.online/register/)发给本班学生。**完整邀请码只显示一次**，再次打开管理页不会显示原码。
3. 管理页可查看已使用名额与到期时间；招满后或不再需要注册时，点击“停用此邀请码”即可停止新入班。
4. 忘记邀请码或需要更换时重新生成。**重新生成会使同班旧码立即失效**；已加入班级的学生不受影响。不要把邀请码放进公开课程、GitHub 仓库或公开评论。

每成功加入一个新学生占用一个名额；已加入同一班的学生再次提交不会重复占用。过期、撤销、名额用完或签发老师的任教权限失效后，邀请码不能继续接收新学生。学生入班后即可访问该班面向有效学生开放的内容，包括已发布作业，以及达到公布条件的班级答案。

### 导入班级名册（另一种建账号方式）

如果希望先建立学校统一名册，可从个人主页点击“管理班级名册”，或打开[班级名册](https://rachelteacher.online/teacher/roster/)。页面会列出可管理的班级及其编号。对于准备自助注册的新学生，无需先导入同一学号。

CSV 表头必须依次为 `student_id,name,class_id`。学号按文本填写，姓名与已有账号一致，班级编号使用页面列出的实际编号。粘贴后点击“预检整批名册”，核对预览，再点击“确认导入这份名册”。内容变更后需重新预检；有冲突的整批数据不会部分写入。

导入新学生账号不等于已经激活。管理员须核验身份，私下向本人发放凭证；签发方式见[部署手册](../deploy/README.md#生产主机)。

### 编辑草稿、检查预览、发布

1. 从个人主页“准备课程资料”下点击“编辑课程”，或打开[课程编辑](https://rachelteacher.online/teacher/courses/)，再选择获授权课程。
2. 在“课程介绍”填写名称、简介，点击“保存课程介绍”。
3. 在“新增章节”填写章名和正文，点击“添加到草稿”。已有章节展开“编辑章节信息”后可“保存本章”“上移一章”“下移一章”或“从草稿移除章节”。正文可直接输入文字；需要保留复杂排版的内容，可作为 Word 或 PDF 资料上传。
4. 展开章节的“新增或替换资料”，选择新增资料或要替换的资料，填写资料名称，上传“课件原件”。支持 PPT、PPTX、DOC、DOCX、PDF，每份文件最多 50 MiB；不支持的格式需先转换。配套 PDF 也受相同文件大小限制，PDF 最多 500 页。
5. Office 原件可以一并上传“配套 PDF 预览”，或等待服务器转换。点击“保存资料至草稿”。

自动转换期间，编辑页会显示等待或正在生成预览；稍后刷新页面。显示“预览已就绪”后，点击“查看 PDF 预览”核对页数与排版。失败时原件保留，可点击“重新生成……的预览”；反复失败时可通过替换资料上传原件和配套 PDF。

课程页的“预览 PDF”和草稿中的“查看 PDF 预览”会打开站内阅读器。可用“上一页”“下一页”、缩放、“适合宽度”和“旋转 90°”查看资料；窄屏放大后可在页面区域内滚动。加载失败时可“重新加载”，也可“下载原件”。

每个编辑区需要分别保存。通过“预览草稿”检查整门课程，确认全部资料预览可用后，在页面末尾点击“确认发布整门课程”。保存草稿不会替换访客正在读取的已发布内容；发布后再用“查看已发布课程”核对结果。若提示草稿被其他编辑更新，请对照页面保留的提交内容和最新草稿后重新操作。

课程和章节页提供固定链接，更新正文和替换资料后仍可用这些链接访问。要撤下某份资料，先从草稿移除，再发布课程。公开课程中的材料允许匿名访问，学生作业、名册、成绩和答案应使用各自的专用功能。

## 教师：布置作业与查收

从已发布章节点击“向……布置本章作业”，可自动关联该章节；也可从“班级成绩册”点击“布置作业”。

填写作业标题、要求、北京时间截止和满分，点击“向本班发布作业”。从章节入口进入时无需手抄章节编号；从其他入口进入时，关联章节为可选项。截止时间必须晚于发布时刻。

作业页的“收件名单”显示有效学生的最新成功版本与未交状态。截止前可以进入“延长截止时间”，填写新时间和延期原因，再点击“确认延期”。本班答案公布后不能再延长截止或重开该作业；补练应另建作业。

## 学生：照片提交、回执与 PDF 重交

1. 从个人主页“我的作业”，或已发布章节的“本班作业”进入目标作业，核对班级、要求与北京时间截止。
2. 用“拍照添页”逐页拍摄，或通过“相册或文档”选文件。一次可交 **1–10 张 JPEG/PNG 照片，或一份 PDF、DOC、DOCX 文档**，合计不超过 **20 MiB**。文档与照片不能混交；其他格式需先转换。
3. 照片选入后，用“上移”“下移”“移除”调整清单。确认页序与内容后点击“确认并提交整版”。
4. 成功后打开“整版收件回执”，核对所属学生、版本号、回执编号及有序附件。页面显示“已收齐”才表示这一版全部收件完成。保留原件和回执编号。
5. 要主动重交 PDF，返回作业页，选择 PDF 并重新提交。新版本有独立回执，旧成功版本仍保留；“我的历史回执”可查看历次成功提交。

网络未确认、显示处理中或未跳转到回执时，先保留原文件，使用原页序重试。刷新页面后网站会尝试核对上次提交；需要重新选文件时应选择原来那一组。只有明确要提交不同内容时才使用“另起一版（使用新编号）”。

截止以服务器收齐并校验整组文件后的登记时间判断，不以开始选文件或点击按钮的时间判断；请预留上传时间。已在截止前登记的一版可以在截止后继续确认，截止后不能另起新版本。

## 教师：成绩册、代交与指定版本批阅

### 查未交名单与代交

从个人主页点击“打开班级成绩册”，或从课程目录进入“班级成绩册”。

先“切换班级”，再按“姓名或完整学号”“作业”“当前状态”筛选。同名学生须结合完整学号核对。“导出当前筛选全部页 CSV”导出全部匹配页；顶部全班平均按该班该次作业的已发布成绩计算，不随姓名筛选改为局部平均。

点击作业列标题进入作业页。在“教师代交”中选择“所属学生”、填写“代交说明”，再选文件并提交。选择学生后页面会显示目标人、作业和上次成功版本；切换所属学生会清空此前选入的文件及说明。代交与学生自交采用相同的截止、格式、总量和整版回执规则，回执会记明教师操作与说明。

### 批阅与发布成绩

1. 在作业的收件名单中点击“批阅本版”；也可进入“批改与成绩”，在版本列表中选择“批阅此版”。
2. 核对学生学号和标题中的 V 版本。即使学生随后重交，当前打开的批阅仍属于原版本。
3. 在“作答与页上批注”中选择附件，用“上一页”“下一页”、缩放和“旋转 90°”核对作答。“手写笔”直接书写；“文字锚点”先输入文字，再点页上位置或“放在页中央”。可“撤销本页上一笔”。
4. Word 预览尚未生成时可“刷新预览状态”；转换失败可“重新生成预览”，也可“下载原件”。
5. 输入整版得分和个人评语，点击“保存批阅草稿”。翻页保留的是当前页面中的修改，保存后才写入网站；离开页面前先保存。
6. 点击“预览成绩发布名单”，每名学生选择一个待公布版本，核对版本、得分和草稿修订号，再点击“确认发布所选成绩”。

“未交”“已交待批”“草稿待发布”“已发布”是不同状态。已发布 **0 分** 是有效成绩，不等于未交。重交或改分尚未发布时，学生仍看到原已发布分数及其批阅版本。修改分数后须再次保存并发布；原发布记录保留。

例如，满分 20，两位已发布学生分别为 16 和 0 分，另有一人待批，则全班平均为 8/20、40%、计入 2 人。

## 教师：标准答案与错题判定

在作业页点击“管理标准答案”。填写试卷名称、试卷版本及逐题题号、知识点、题干、标准答案；“再加一题”增加题目，可选上传答案 PDF，然后点击“保存新修订”。

答案修改会产生新修订。若题号、题干、知识点或题目数量改变，需要使用新的试卷版本号。逐题批阅前先准备相应试卷与答案，在批阅页核对“本次批阅使用的答案修订”，必要时“切换并核对题号”。

要生成个人错题，在“判定与评分”逐题选“错题”，确认作答附件、作答页，填写错因，再保存批阅草稿并发布成绩。系统不会从总分低推断具体错题。

本班截止后，还需要教师明确点击“向本班发布标准答案”。到点不会自动公布，提前点击会被拒绝。同一份试卷用于多个班时，各班分别控制截止与公布。

本班标准答案向全部有效学生开放，包括未交作业者；个人评语、页上批注和错题还需本人批阅已经发布，并且本班已公布该批阅所用的答案修订。更正答案后应核对批阅采用的修订，避免把尚未公布的答案草稿用于面向学生的批阅。

## 学生：查看成绩、答案与复习错题

- 从“我的成绩”进入具体作业，核对得分、满分和批阅版本。新版本已收件但未公布成绩时，页面会提示等待发布。
- 在作业页点击“查看本班标准答案与发布状态”。显示“待教师公布”时，请等待教师手动公布，截止本身不会打开答案。
- 个人批阅详情会在满足发布条件后显示教师评语和页上批注。
- 从“我的错题”按课程、试卷、题号、知识点或复习状态筛选；点击“回到 V……的第……页批阅”可回看当时作答。复习后点击“标记已复习”，也可重新列入待复习。
- 错题卡保留当时公布的答案与原作答版本，不会因后来换卷或重交而移到别人的资料上。

学生只能访问本人的回执、成绩、附件及错题。换账号后，原账号的私人链接也不能继续读取。

## 常见情况

| 页面情况 | 处理方式 |
| --- | --- |
| 公开入口暂时无法载入课程 | 先直接打开 `https://rachelteacher.online/`；若也无法访问，将发生时间和错误文字提供给维护人员。 |
| 已登录但没有课程编辑或班级入口 | 联系管理员核对课程编辑权、任教关系或有效选课。 |
| 管理员登录后没有“编辑课程” | 在后台为这个账号添加 `Course editor`；管理班级还需添加有效的 `Teaching assignment`。 |
| 注册提示账号已存在 | 已设置过密码则登录；已导入名册但未激活则向老师索取本人专属激活凭证，不要改用他人学号。 |
| 邀请码无效、过期或名额已满 | 向任课老师索取当前有效的邀请码；新生成的码会替代同班旧码。 |
| 已有账号想加入另一班 | 登录后进入 `/join/`，输入目标班级的邀请码。 |
| 课程预览反复失败 | 在草稿中重试；仍失败时上传对应的配套 PDF，并向维护人员报告。 |
| 提交没有成功回执 | 保留原件、提交时间与页面提示，用原清单重试或核对历史回执；不要仅凭上传动画判断收件成功。 |
| 本人成绩已发布，但评语、批注或错题未显示 | 核对本班是否公布了对应答案修订；普通分数与含解答内容分开发布。 |
| 版本冲突提示 | 保存页面保留的输入内容，重新打开最新草稿，核对后再提交。 |
| 地址不存在或无权限 | 先核对当前账号及班级；私人链接只对本人或获授权教师开放。 |

遇到问题时向维护人员提供页面路径、操作时间、作业和版本号、错误文字；私下传递必要证据，不将密码、激活凭证或学生文件放进公开 GitHub Issue。
